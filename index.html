Minimal OS

A lightweight, distraction-free custom Android 12.1 (LineageOS 19.1) ROM built specifically for dumbphones and flip phones like the Cat S22 Flip.

What's Included

  • Minimalist Launcher (Trebuchet) & monochrome Dialer
  • Keypad-friendly navigation & SystemUI tweaks
  • Clean, bloat-free Android 12.1 base

Sync the Source

repo init -u https://github.com/MinimalOS-ROM/android.git -b minimal-1.0
repo sync -c -j$(nproc)

Follow development on GitHub (MinimalOS-ROM).
